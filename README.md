# 낚시 민족 (fish_People)

낚시가 취미인 시니어를 위한 취미 질 향상 앱.
**날씨 보고 나가서, 사진 한 장으로 기록하세요.**

파일 하나(`index.html`)로 동작합니다. 빌드·설치가 필요 없고, 더블클릭하면 바로 열립니다.

## 화면

| 화면 | 내용 |
|------|------|
| 오늘 | 낚시지수(0~100) · 시간대 6칸 · 지도 · 주변 꿀스팟 18곳 |
| 기록 | 카메라/파일로 사진 → 어종 판별 → 크기 재기 → 법규 판정 → 저장 |
| 도감 | 32종 도감 · 배지 10종 · 주간 챌린지 |
| 친구 | 초대 코드 · 이번 달 랭킹 · 조과 피드 |
| 설정 | 닉네임 · 공개 범위 · 법규 데이터 기준일 |

## 쓰는 데이터

- **날씨** — [Open-Meteo](https://open-meteo.com) (가입·API 키 불필요)
  - 기온·습도·강수·풍속·기압·WMO 기상코드
  - 풍속 단위는 **m/s** 고정 (낚시지수 임계값이 m/s 기준으로 맞춰져 있음)
- **어종 판별** — [Claude](https://claude.com) (`claude-opus-5`) · 아래 *어종 판별* 참고
- **지도** — [Leaflet](https://leafletjs.com) + OpenStreetMap 타일 (한글 지명)
- **아이콘** — Google Material Symbols
- **초대 코드** — [Supabase](https://supabase.com) (`fp_angler` 테이블)

모두 CDN·네트워크에서 불러오므로 **인터넷 연결이 필요**합니다.

## 기록·설정 저장

조과 기록은 **브라우저 안에만** 있습니다. 서버로 나가는 건 초대 코드와 친구 관계뿐입니다.

| 키 | 내용 |
|----|------|
| `fishdex.v1` | 조과 기록 · 도감 · 배지 · 친구 · 스팟 후기 · 내 초대 코드 · `secret` |
| `nm.theme` | 밝게/어둡게 선택 |
| `nm.loc` | 내 위치 |

### 서버에 올라가는 것

친구가 내 코드를 쳤을 때 실제로 찾아지려면 코드가 어딘가에 있어야 합니다.
그래서 `fp_angler` 한 줄을 남깁니다 — **초대 코드와 닉네임**뿐이고, 조과·사진·위치는 올라가지 않습니다.
친구 요청과 연결된 친구 관계도 서버에 남습니다(아래 *친구* 참고).

로그인이 없어서 본인 확인은 `secret`(UUID)으로 합니다. 앱이 만들어 보내고 `localStorage`에 보관하며,
수정할 때 `x-angler-secret` 헤더로 보냅니다. 서버의 RLS 정책이 이 값을 대조해 **자기 줄만** 고치게 합니다.
`secret`은 `anon` 권한으로 읽을 수 없어, 남의 것을 조회해 갈 수 없습니다.

코드 형식은 `AB23-CD45`입니다. 헷갈리는 `I`·`L`·`O`·`0`·`1`은 쓰지 않고,
같은 규칙을 앱과 DB의 `CHECK` 제약이 **양쪽에서** 검사합니다.

서버가 안 되더라도 앱은 그대로 돌아갑니다. 코드는 로컬에서 만들어 쓰고, 등록만 조용히 건너뜁니다.

## 친구

코드를 입력하면 **요청이 상대에게 갑니다.** 상대가 수락해야 연결되고, 거부할 수도 있습니다.
서로의 기기에서 진짜로 오가므로, 시연할 때 휴대폰 두 대로 보여 줄 수 있습니다.

| 표 | 내용 |
|----|------|
| `fp_friend_request` | 대기 중인 요청 (`from_id`, `to_id`) |
| `fp_friend` | 연결된 친구. 양방향으로 두 줄 |

**상태 컬럼이 없습니다.** 요청 줄이 있으면 대기 중이고, 수락하면 `fp_friend` 두 줄로 옮겨 가며 사라집니다.
거부·취소도 그냥 지웁니다. 그래서 보낸 쪽은 줄의 유무만 보고 결말을 압니다 —
*줄이 있으면 대기, 없는데 친구면 수락, 없는데 친구도 아니면 거부.*

### 남의 것은 보이지 않습니다

- 요청과 친구 관계는 **당사자에게만** 보입니다(`fp_is_me_id`로 `x-angler-secret`을 대조).
- 요청은 **본인 이름으로만** 보낼 수 있습니다. 남의 id를 `from_id`에 넣으면 거부됩니다.
- 수락은 서버 함수 `fp_accept_friend`로만 합니다. 받은 사람 본인이고 그 요청이 실제로 있을 때만 움직입니다.
- 한 사람이 동시에 띄울 수 있는 요청은 50건까지입니다.

### 조과는 아직 데모입니다

친구의 **닉네임은 서버의 진짜 값**이지만, 랭킹·피드에 보이는 **조과 기록은 코드로 만들어 낸 데모 데이터**입니다.
조과는 아직 `localStorage`에만 있어서 서로 볼 수 없기 때문입니다.

상대 기기가 없을 때를 위해, 서버에 못 올린 요청에는 *데모: 수락됨* 버튼이 남습니다.

## 어종 판별

사진을 올리면 **Claude 비전**(`claude-opus-5`)이 도감 45종 안에서 후보 3개를 확신도와 함께 골라 줍니다.
왜 그렇게 봤는지도 한 줄로 보여 줍니다 — "등지느러미 가시가 뚜렷하고 체고가 높음" 같은 식입니다.

### 키는 브라우저에 없습니다

이 앱은 공개 정적 사이트입니다. `index.html`에 API 키를 넣으면 개발자 도구를 여는 누구나 가져다 씁니다.
그래서 키는 **서버리스 함수에만** 둡니다.

```
브라우저 (640px JPEG)  →  /api/identify  →  Claude
                              ↑
                    ANTHROPIC_API_KEY (Vercel 환경변수)
```

`api/identify.js`가 하는 일:
- 브라우저가 보낸 어종 목록의 **형식을 검사**합니다 — id는 `[a-z0-9_]`, 이름은 공백 없는 24자 이내.
  도감 이름은 전부 공백이 없어서(가장 긴 것이 `흰꼴뚜기(무늬오징어)`), 이름 칸에 문장 모양의 지시문을 실을 수 없습니다.
- 응답을 **구조화 출력**(`json_schema`)으로 묶습니다. `id`가 목록의 enum이라 목록 밖 값이 나올 수 없습니다.
- Origin 검사와 분당 호출 제한을 겁니다. 둘 다 완전한 방어는 아니니
  **[Anthropic 콘솔에서 지출 한도(Spend limit)를 걸어 두세요.**](https://console.anthropic.com/settings/limits)

### 켜는 법

1. [console.anthropic.com](https://console.anthropic.com)에서 API 키 발급
2. Vercel → 프로젝트 → Settings → Environment Variables → `ANTHROPIC_API_KEY` 추가
3. 재배포 (`vercel --prod`)

### 안 켜도 앱은 돌아갑니다

키가 없거나, 함수 호출이 실패하거나, 인터넷이 끊겼거나, `file://`로 열었으면
**기존 색·형태 추정으로 조용히 되돌아갑니다.** 기록 흐름 자체는 끊기지 않습니다.

비용은 사진 1장에 **약 30원**($0.02)입니다. 사진이 이미 640px JPEG로 줄어 있어 이미지 토큰이 적습니다.

## 알아둘 점

- **위치·카메라는 `file://`에서 동작하지 않습니다.** 브라우저가 권한을 붙여 둘 출처가 없어 거부합니다.
  웹 주소(https)로 열면 정상 동작하며, 그 전까지는 위치를 직접 고르거나 파일에서 사진을 올리면 됩니다.
- **어종 판별은 참고용입니다.** AI든 색·형태 추정이든 틀릴 수 있으므로, 확신도가 55% 미만이면 자동으로 정하지 않고 직접 고르도록 안내합니다.
- **금어기·금지체장·보호종 정보는 참고용 스냅샷**입니다. 시·도 조례와 매년 개정에 따라 달라지므로,
  출조 전 해양수산부·관할 지자체 고시를 확인해야 합니다. (설정 화면에 기준일 표시)
