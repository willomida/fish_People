# 낚시 민족 (fish_People)

낚시가 취미인 시니어를 위한 취미 질 향상 앱.
**날씨 보고 나가서, 사진 한 장으로 기록하세요.**

파일 하나(`index.html`)로 동작합니다. 빌드·설치가 필요 없고, 더블클릭하면 바로 열립니다.

## 화면

| 화면 | 내용 |
|------|------|
| 오늘 | 낚시지수(0~100) · 시간대 6칸 · 지도 · 주변 꿀스팟 18곳 |
| 기록 | 카메라/파일로 사진 → 어종 판별 → 크기 재기 → 법규 판정 → 저장 |
| 도감 | 32종 도감 · 배지 10종 · 주간 챌린지 |
| 친구 | 초대 코드 · 이번 달 랭킹 · 조과 피드 |
| 설정 | 닉네임 · 공개 범위 · 법규 데이터 기준일 |

## 쓰는 데이터

- **날씨** — [Open-Meteo](https://open-meteo.com) (가입·API 키 불필요)
  - 기온·습도·강수·풍속·기압·WMO 기상코드
  - 풍속 단위는 **m/s** 고정 (낚시지수 임계값이 m/s 기준으로 맞춰져 있음)
- **지도** — [Leaflet](https://leafletjs.com) + OpenStreetMap 타일 (한글 지명)
- **아이콘** — Google Material Symbols
- **초대 코드** — [Supabase](https://supabase.com) (`fp_angler` 테이블)

모두 CDN·네트워크에서 불러오므로 **인터넷 연결이 필요**합니다.

## 기록·설정 저장

조과 기록은 **브라우저 안에만** 있습니다. 서버로 나가는 건 초대 코드뿐입니다.

| 키 | 내용 |
|----|------|
| `fishdex.v1` | 조과 기록 · 도감 · 배지 · 친구 · 스팟 후기 · 내 초대 코드 · `secret` |
| `nm.theme` | 밝게/어둡게 선택 |
| `nm.loc` | 내 위치 |

### 서버에 올라가는 것

친구가 내 코드를 쳤을 때 실제로 찾아지려면 코드가 어딘가에 있어야 합니다.
그래서 `fp_angler` 한 줄만 남깁니다 — **초대 코드와 닉네임**뿐이고, 조과·사진·위치는 올라가지 않습니다.

로그인이 없어서 본인 확인은 `secret`(UUID)으로 합니다. 앱이 만들어 보내고 `localStorage`에 보관하며,
수정할 때 `x-angler-secret` 헤더로 보냅니다. 서버의 RLS 정책이 이 값을 대조해 **자기 줄만** 고치게 합니다.
`secret`은 `anon` 권한으로 읽을 수 없어, 남의 것을 조회해 갈 수 없습니다.

코드 형식은 `AB23-CD45`입니다. 헷갈리는 `I`·`L`·`O`·`0`·`1`은 쓰지 않고,
같은 규칙을 앱과 DB의 `CHECK` 제약이 **양쪽에서** 검사합니다.

서버가 안 되더라도 앱은 그대로 돌아갑니다. 코드는 로컬에서 만들어 쓰고, 등록만 조용히 건너뜁니다.

## 알아둘 점

- **위치·카메라는 `file://`에서 동작하지 않습니다.** 브라우저가 권한을 붙여 둘 출처가 없어 거부합니다.
  웹 주소(https)로 열면 정상 동작하며, 그 전까지는 위치를 직접 고르거나 파일에서 사진을 올리면 됩니다.
- **어종 사진 판별은 색·형태 기반의 간단한 추정**이라 정확하지 않습니다. 확신도가 낮으면 직접 고르도록 안내합니다.
- **금어기·금지체장·보호종 정보는 참고용 스냅샷**입니다. 시·도 조례와 매년 개정에 따라 달라지므로,
  출조 전 해양수산부·관할 지자체 고시를 확인해야 합니다. (설정 화면에 기준일 표시)
